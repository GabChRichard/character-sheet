# Feuille de Personnage — Mode d'emploi étudiant

Bienvenue sur votre fiche de personnage ! Cette page suit vos projets, vos compétences et vos badges tout au long de la session.

## 🐙 Se connecter

1. Ouvrez la page de l'application.
2. Cliquez sur **"Se connecter avec GitHub"**.
3. Utilisez le **compte GitHub dont vous avez communiqué le username à votre professeur**. Si vous en avez plusieurs, faites attention à choisir le bon.

Aucun mot de passe, aucun code à retenir — votre compte GitHub *est* votre identifiant. La première connexion active automatiquement votre profil ; les suivantes vous y ramènent directement.

### "Aucun compte trouvé"

Si vous voyez cet écran après vous être connecté, ça veut dire que le username GitHub détecté ne correspond à aucun profil enregistré. Deux causes possibles :
- **Vous êtes connecté avec le mauvais compte GitHub** → cliquez sur "Se déconnecter" puis reconnectez-vous avec le bon.
- **Le username communiqué à votre professeur contient une erreur** → contactez-le pour qu'il corrige l'information, puis cliquez sur "🔄 Réessayer".

## ✏️ Éditer votre profil

- Cliquez sur le crayon ✏️ à côté de votre nom pour modifier votre **photo de profil**, votre **alias**, votre **objectif** et vos **intérêts** (6 maximum).
  - L'alias doit être unique : s'il est déjà pris, un message vous demandera d'en choisir un autre.
  - Photo : formats image standards, **5 Mo maximum** — l'image est automatiquement redimensionnée et compressée après l'upload.
- Dans le panneau "Savoir-être", cliquez sur "+ Ajouter" pour choisir vos savoir-être dans le catalogue (**10 maximum**).
- Les boutons en haut à droite (**Dark**, **Parchemin**, **Cyber**) changent le thème visuel de votre fiche.

## 📁 Gérer vos projets

- **Ajouter un projet** : bouton "+ Ajouter" dans le panneau "Inventaire Projets". Remplissez le nom, la description, le cours associé, la session et l'année, le type de réalisation (**Solo** ou **Équipe**), une miniature optionnelle, les compétences mobilisées et un lien optionnel.
- **Solo ou Équipe** : un projet réalisé en équipe vaut **25 % moins de points** par compétence.
- **Compétences mobilisées** : cochez uniquement ce que **vous** avez personnellement fait — même en équipe, décrivez votre propre implication, pas celle du groupe — puis indiquez le temps investi.
- **Éditer / supprimer** : cliquez sur un projet pour ouvrir sa fiche détaillée, où ces options sont disponibles si c'est votre projet.
- **Épingler** : vous pouvez épingler jusqu'à **3 projets** pour les mettre en avant en haut de votre inventaire.

Vos compétences (panneau "Compétences" et radar sous votre profil) sont calculées automatiquement à partir des projets que vous documentez et des endossements reçus — rien à remplir manuellement de ce côté.

## 🔍 Visiter un pair et endosser ses projets

1. Dans le panneau "Chercher un pair", entrez l'alias d'un autre étudiant (visible sur son profil).
2. Vous accédez à son profil en mode lecture seule (indiqué par le bandeau "Mode Visiteur").
3. Ouvrez un de ses projets et cliquez sur "👍 Endosser le projet" — ça contribue à son score de compétences. Vous pouvez retirer votre endossement à tout moment. Vous ne pouvez pas endosser vos propres projets.
4. Cliquez sur "Retour à mon profil" (en haut de la page) pour revenir à votre propre fiche.

## 🚪 Se déconnecter

Cliquez sur **Déconnexion** dans la barre du haut avant de quitter — **c'est particulièrement important si vous utilisez un poste informatique partagé** (labo, ordinateur commun) : sans déconnexion explicite, votre session reste active tant que le navigateur n'est pas fermé et pourrait être visible par la prochaine personne sur ce poste.

Par sécurité, vous êtes aussi déconnecté automatiquement après **1 heure d'inactivité** (un avertissement s'affiche 60 secondes avant — bougez la souris ou appuyez sur une touche pour rester connecté).

## ❓ Besoin d'aide ?

Contactez votre professeur si :
- vous n'arrivez pas à vous connecter (voir "Aucun compte trouvé" ci-dessus),
- un badge ou une information sur votre profil semble incorrecte,
- vous avez besoin d'un rattachement/correction de votre compte.
